# 美図決算（ビジュ決算）β

日本の上場企業の決算を「絵でみる儲けの流れ」（損益）と「絵でみるファイナンス」（貸借対照表）の2枚の図にするアプリ **BizKessan** のデータ置き場です。

## しくみ

- 毎日1回（日本時間22時台）、GitHubの自動実行が東証の適時開示（TDnet）から決算短信のXBRLを取り込みます。
- 図に使う**数字だけ**を `data/companies/<銘柄コード>.json` に保存します。短信のPDFやXBRLのファイルそのものは保存・配布しません。
- アプリはこのフォルダの数字を読んで、スマホの中で図を描きます。
- 同じ期に有価証券報告書（EDINET）の数字があれば、そちらを優先します（EDINETの取り込みは準備中）。

## ルール

- 連結財務諸表を使う。連結がない会社は個別の数字で描き、そのことを明記する
- 日本基準とIFRSの違いを注記する（IFRSの科目の置き換えを明記）
- 「自己資本」ではなく「株主資本」と書く

## 出典

東京証券取引所 適時開示情報閲覧サービス（TDnet）の決算短信をもとに HIKICHI ＆ Company が作成。
数字は各社の開示資料に基づく事実情報です。誤りに気づいた場合はお知らせください。

## アプリの組み立て（開発者向け）

`app/` の画面ファイルを `android/app/src/main/assets/` に写してから組み立てます。署名の鍵はこのリポジトリには入れていません（環境変数 `KS_FILE` と `KS_PASS` で渡します）。
